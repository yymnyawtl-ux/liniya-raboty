# Лендинг «Линия работы»

Статический сайт для предварительного согласования рекламного трафика. На публичной странице используется нейтральная концепция вакансий клиентского сервиса без упоминания конкретного работодателя или партнёрской программы.

## Перед запуском рекламы

1. Заменить демонстрационную обработку формы на официальную ссылку или интеграцию партнёрской программы.
2. Указать оператора персональных данных и его реквизиты.
3. Заменить демонстрационный текст политики на согласованный юридический документ.
4. Проверить актуальные проекты, географию, доход и графики у персонального менеджера.

Фотография для главного экрана создана специально для проекта и не содержит логотипов или фирменной символики работодателя.
